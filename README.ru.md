## ✨ Возможности

- 🎯 **Быстрый доступ**: Мгновенно открывайте файлы, выполняйте команды, переходите по ссылкам или запускайте скрипты одним кликом.
- 🎨 **Выбор иконок**: Встроенная библиотека иконок Lucide с поиском и предпросмотром.
- 🏷️ **Три режима просмотра**: Переключайтесь между списком, вкладками и папками.
- 📁 **Режим папок**: Сетка папок в стиле Android с перетаскиванием, авто-раскрытием при наведении, закреплением, закрытием по клику и редактируемыми именами.
- 📁 **Управление категориями**: Группируйте кнопки по категориям; изменяйте порядок категорий и кнопок с помощью длительного нажатия и перетаскивания.
- ⚙️ **Гибкая настройка**: Полностью настраиваемый макет панели, стили кнопок и анимация.
- 📱 **Адаптивный дизайн**: Оптимизировано для настольных и мобильных устройств.
- 🌙 **Адаптация к теме**: Бесшовно адаптируется к светлой и тёмной темам Obsidian.
- 🎛️ **Отдельная вкладка настроек**: Управляйте всеми настройками плагина в отдельной удобной вкладке.
- 🔄 **Мгновенное обновление**: Все изменения вступают в силу немедленно — перезагрузка не требуется.
- 🛡️ **Валидация форм**: Обязательные поля (имя кнопки, путь к файлу, ID команды, URL, папка, имя скрипта) подсвечиваются красным, если они пустые.
- 🖱️ **Режим взаимодействия**: Три режима — Заблокировано (только просмотр), Сортировка (перетаскивание), Редактирование (контекстное меню) — переключаются с верхней панели навигации.
- 🧭 **Верхняя панель навигации**: Выпадающие меню для быстрого переключения вида панели, стиля кнопок и режима взаимодействия; а также поиск и доступ к настройкам.
- 🔍 **Поиск**: Панель навигации включает функцию поиска, которая фильтрует категории и кнопки в реальном времени для быстрого доступа.
- 🔗 **Последовательности действий**: Настройте несколько действий для одной кнопки и выполняйте их по порядку одним кликом.

## 🚀 Установка

### 🏪 Установка из каталога плагинов (рекомендуется)

1. Откройте Obsidian и перейдите в **Настройки → Сторонние плагины**.
2. Нажмите **Обзор** и найдите «Buttons Panel».
3. Нажмите **Установить**, затем **Включить**.

### 📦 Ручная установка

1. Скачайте последнюю версию со страницы [Releases](https://github.com/TracingOrigins/obsidian-buttons-panel-plugin/releases).
2. Поместите папку плагина в директорию плагинов Obsidian (обычно `.obsidian/plugins/`, например `ВашеХранилище/.obsidian/plugins/buttons-panel/`).
3. Включите плагин в Obsidian: Настройки → Сторонние плагины.

### 🔧 Установка через BRAT (рекомендуется для бета-тестеров)

1. Установите плагин [BRAT](https://github.com/TfTHacker/obsidian42-brat).
2. В настройках BRAT нажмите «Add Beta plugin».
3. Введите `TracingOrigins/obsidian-buttons-panel-plugin`.
4. Включите плагин.

## 📖 Использование

### 🎯 Открытие панели кнопок

- Используйте командную палитру (Ctrl+P) и выполните «Open buttons panel (right sidebar)».
- Нажмите иконку сетки на левой ленте для быстрого открытия панели и настроек.
- Панель кнопок появится в правой боковой панели для быстрого доступа.

### ⚙️ Открытие настроек панели кнопок

- Используйте командную палитру и выполните «Open buttons panel settings (central content area)».
- Страница настроек откроется в основной области для детальной настройки.
- Вы также можете получить доступ к настройкам через раздел плагинов в настройках Obsidian.

### 🔗 Последовательности действий

- **Последовательности действий**: Настройте кнопку для выполнения нескольких действий последовательно (например, создать файл, вставить шаблон, запустить скрипт). Клик по кнопке выполнит все действия по порядку. Каждое действие может быть разного типа, что значительно расширяет возможности автоматизации и пакетной обработки.
    - **Как настроить**: В редакторе кнопок нажмите «Добавить действие», чтобы добавить несколько действий, и перетаскивайте их для изменения порядка.
    - **Типичные сценарии**: Создание и открытие заметки по шаблону одним кликом, пакетное выполнение команд, автоматизация ежедневных рутин и многое другое.

### 🔗 Поддерживаемые типы действий

- **Открыть файл**: Открыть любой файл в хранилище.
- **Команда**: Выполнить любую команду Obsidian.
- **Открыть ссылку**: Открыть внешнюю веб-ссылку.
- **Создать файл**: Создать новый файл в указанном месте с поддержкой переменных даты (например, `{{DATE:YYYY-MM-DD}}`) и шаблонов.
- **Запустить скрипт**: Запустить пользовательский JS-скрипт из хранилища (поддерживаются форматы скриптов QuickAdd и Components). Скрипты должны находиться в настроенной папке скриптов.

### ✅ Валидация форм

- При создании или редактировании кнопки нажатие «Сохранить» автоматически проверяет все обязательные поля.
- Если обязательное поле пустое, соответствующий ввод подсвечивается красным.
- Красная подсветка исчезает автоматически после заполнения поля.

### 🎛️ Настройки панели

- **Режим просмотра**: Выберите список, вкладки или папки.
- **Стиль кнопок**: Иконка слева от текста или иконка над текстом (в режиме папок всегда используется иконка сверху).
- **Анимация**: Включить анимацию кнопок при наведении.
- **Режим взаимодействия**: Заблокировано (только просмотр), Сортировка (перетаскивание) или Редактирование (создание/редактирование/удаление).
- **Верхняя навигация**: Включить или отключить верхнюю панель навигации.

> Пример: Выберите «Вкладки», чтобы сгруппировать кнопки по категориям.

### 📁 Управление путями

- **Путь к папке шаблонов**: Укажите путь к папке для хранения файлов шаблонов (например, `templates/`). Действие создания файла будет использовать шаблоны из этого пути.
- **Путь к папке скриптов**: Укажите путь к папке для хранения файлов скриптов (например, `scripts/`). Действие запуска скрипта будет загружать файлы скриптов из этого пути.
- **Валидация пути**: Пути проверяются в реальном времени. Недействительные пути подсвечиваются красной рамкой.
- **Создание одним кликом**: Нажмите кнопку «Создать пути», чтобы автоматически создать отсутствующие папки.

> Пример: Укажите папку шаблонов `templates/` и папку скриптов `scripts/`, чтобы функции создания файлов и запуска скриптов работали корректно.

### 🖱️ Режим взаимодействия

Кнопка редактирования на панели навигации открывает выпадающее меню с тремя режимами:

| Режим | Иконка | Поведение |
|------|------|----------|
| 🔒 **Заблокировано** | `lock` | Только просмотр — все взаимодействия отключены (нет перетаскивания, нет контекстного меню) |
| ↕️ **Сортировка** | `arrow-up-down` | Длительное нажатие и перетаскивание для изменения порядка кнопок и категорий |
| ✏️ **Редактирование** | `pencil` | Контекстное меню (правый клик / длительное нажатие) для добавления, редактирования, копирования или удаления |

- Переключайте режимы из выпадающего меню верхней панели навигации или в настройках **Панели**.
- **Перетаскивание доступно только в режиме Сортировки**.
- **Элементы редактирования и контекстные меню доступны только в режиме Редактирования**.

### 📁 Режим папок

Переключитесь в режим папок с панели навигации или в настройках. Категории отображаются как плитки папок в адаптивной сетке.

| Возможность | Описание |
|---------|-------------|
| **Открыть/Закрыть** | Нажмите на плитку, чтобы раскрыть; нажмите снаружи, нажмите ESC или на пустое место (настраивается), чтобы закрыть |
| **Закрепить** | Нажмите 📌, чтобы зафиксировать — папка остаётся открытой до открепления или переключения на другую папку |
| **Изменить имя** | Нажмите на имя папки, чтобы переименовать (настраивается в параметрах) |
| **Переупорядочить папки** | Длительное нажатие и перетаскивание в режиме сортировки |
| **Перетаскивание между папками** | Перетащите кнопку наружу → авто-закрытие → наведите на 0,6 сек. на другую плитку → авто-раскрытие → продолжайте сортировку |
| **Авто-прокрутка** | Перетаскивание у краёв внутри раскрытой папки вызывает прокрутку |

**Настройки папок**: редактируемое имя папки, отображение количества кнопок, закрытие по клику на пустое место.

### 📦🔀 Перетаскивание для сортировки

Когда активен **режим Сортировки** и **поиск не активен**, используйте длительное нажатие и перетаскивание (на десктопе также работает длительное нажатие мыши):

| Цель | Список | Вкладки | Папки |
|--------|-----------|-------------|-------------|
| **Кнопки** | Длительное нажатие на кнопку, затем перетащите для изменения порядка внутри категории; перетащите на вкладку/зону другой категории для перемещения между категориями | То же; сетка активной вкладки поддерживает перетаскивание | Перетаскивание внутри раскрытой папки или между папками; наведите на 0,6 сек. на плитку для авто-раскрытия |
| **Категории** | Длительное нажатие на блок категории (заголовок или область без кнопок), затем перетащите вертикально для изменения порядка | Длительное нажатие на вкладку, удерживайте ~0,4 сек. над другой вкладкой для подтверждения, затем отпустите | Длительное нажатие на плитку для изменения порядка в сетке |

- Порядок сохраняется автоматически при отпускании.
- Сортировка недоступна в режимах **Заблокировано** или **Редактирование**, а также при **активном поиске**.

#### 📱 Сенсорные жесты (Мобильные)

- **Прокрутка панели**: Проведите вверх/вниз по панели (список) или влево/вправо по панели вкладок (вкладки) без длительного нажатия.
- **Перетаскивание**: Длительное нажатие (~0,5 сек.) на кнопку или категорию/вкладку, затем перетащите. Во время перетаскивания прокрутка панели блокируется, чтобы элемент следовал за пальцем.
- Если быстрое смахивание обнаружено до завершения длительного нажатия, жест интерпретируется как прокрутка, и перетаскивание не начинается.

### 🧭 Верхняя панель навигации

- Панель оснащена верхней панелью навигации со следующими функциями:
    - **Переключение вида панели**: Переключение между вкладками и списком.
    - **Переключение стиля кнопок**: Мгновенное изменение стиля кнопок.
    - **Режим взаимодействия**: Переключение между Заблокировано, Сортировка и Редактирование через выпадающее меню.
    - **Поиск**: Нажмите иконку поиска, чтобы открыть поле поиска и фильтровать категории и имена кнопок в реальном времени.
    - **Настройки панели**: Открыть страницу настроек панели одним кликом.
- **Прокрутка панели вкладок** (режим вкладок, много вкладок): На мобильных — свайп влево/вправо; на десктопе — наведите на панель вкладок, удерживайте **Shift** и прокручивайте колёсико мыши горизонтально.
- Панель навигации разработана для эффективности и удобства использования.

### 🔍 Поиск

- Нажмите иконку поиска на панели навигации, чтобы открыть поле поиска.
- После ввода ключевых слов панель автоматически отфильтрует и покажет соответствующие категории и кнопки.
- Поиск фильтрует только имена категорий и имена кнопок, с обновлением в реальном времени.
- Нажмите кнопку очистки или закройте поле поиска, чтобы сбросить критерии поиска.

### 🧩 Функция скриптов

- В редакторе кнопок выберите «Скрипт» в качестве типа действия и выберите или введите имя файла скрипта (только `.js`).
- Файлы скриптов должны находиться в папке скриптов, указанной в настройках плагина (например, `scripts/`). Вы можете настроить этот путь во вкладке настроек.
- Поддерживаются два формата скриптов:
    - **Формат QuickAdd**: Скрипт должен экспортировать асинхронную функцию, например:

        ```js
        // scripts/hello.js
        module.exports = async function (params, app, plugin, notice) {
            notice('Привет из скрипта!');
            // Здесь можно использовать Obsidian API, экземпляр плагина и т.д.
        };
        ```

    - **Формат Components**: Скрипт должен экспортировать объект, чей `default.entry` является асинхронной функцией, например:

        ```js
        // scripts/components-demo.js
        exports.default = {
            entry: async function (params, app, plugin, notice) {
                notice('Привет из Components скрипта!');
                // Здесь можно использовать Obsidian API, экземпляр плагина и т.д.
            },
        };
        ```

- В окружение скрипта внедряются `app` (экземпляр Obsidian), `plugin` (экземпляр плагина) и `notice` (метод уведомления).
- Ошибки скриптов автоматически перехватываются и отображаются в виде уведомлений.
- **Примечание по безопасности**: Не запускайте скрипты из ненадёжных источников. Выполнение скриптов сопряжено с inherent рисками.

> Пример: Напишите скрипты пакетной обработки или автоматизации и запускайте их одним кликом.  
> Пример: Настройте кнопку с действиями «Создать файл → Вставить шаблон → Запустить скрипт», и все они будут выполнены по порядку одним кликом.

## 🛠️ Разработка

- Клонируйте этот репозиторий.
- Убедитесь, что NodeJS не ниже v18 (`node --version`), рекомендуется LTS-версия.
- Выполните `npm install` для установки зависимостей.
- Выполните `npm run dev` для запуска режима разработки с live-компиляцией (автоматически развёртывается в тестовое хранилище).
- Выполните `npm run build` для сборки production-версии и развёртывания в тестовое хранилище.
- Выполните `npm run lint` для проверки качества кода.
- Для развёртывания в пользовательское хранилище создайте файл `.env` в корне проекта и добавьте: `VAULT_PATH=/путь/к/вашему/хранилищу`.
